# 🚀 Trabajar con el proyecto desde Git Bash

## 1. Clonar el repositorio

La primera vez que descargue el proyecto en un computador:

```bash
git clone https://github.com/yavodev/yavodev.github.io.git
```

Entrar a la carpeta:

```bash
cd yavodev.github.io
```

---

## 2. Verificar la conexión con GitHub

```bash
git remote -v
```

Debe aparecer:

```text
origin  https://github.com/yavodev/yavodev.github.io.git (fetch)
origin  https://github.com/yavodev/yavodev.github.io.git (push)
```

---

# 🔄 Flujo de trabajo diario

Antes de comenzar a trabajar:

```bash
git pull
```

Después de realizar cambios:

```bash
git status
```

Agregar los archivos modificados:

```bash
git add .
```

Crear el commit:

```bash
git commit -m "Actualizo mi portafolio"
```

Subir los cambios a GitHub:

```bash
git push
```

## ⚠️ Importante

No es necesario volver a utilizar `git clone` cada vez.

`git clone` se utiliza normalmente **una sola vez** para crear la copia local del repositorio.

Después se trabaja con:

```bash
git pull
```

y

```bash
git push
```

para sincronizar el proyecto con GitHub.
